# Source, dependencies and assets

- `src/` and `tests/`: application, encoder, renderer and tests developed for this project with AI coding assistance, then organized for public release. No external GIF encoder source is bundled.
- `assets/icon.svg` and `src/app.ico`: project icon design. The ICO was generated from the SVG during development; rebuilding the application uses the checked-in ICO, without requiring the original image-generation tooling.
- `assets/demo.gif`, `assets/interface.png` and `examples/default.gifcfg`: generated by this application using generic sample text. The interface image is a self-rendered hidden application window, not a desktop capture.
- Windows Win32 and GDI+ APIs are system dependencies. Microsoft Visual Studio Build Tools and Windows SDK are separately installed build tools; they are not redistributed in the repository. The executable statically links the MSVC runtime under the applicable Microsoft redistribution terms.
- Fonts are selected from the user's installed fonts. No Microsoft or other font files are bundled. Users remain responsible for licensing the fonts and content they use in their own output.
- Test-only dependencies: [Pillow](https://github.com/python-pillow/Pillow) (HPND license) and [NumPy](https://github.com/numpy/numpy) (BSD-3-Clause). Installed separately; neither is included in the portable release.
