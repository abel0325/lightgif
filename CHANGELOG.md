# Changelog

## 1.0.0 — 2026-10-31

First public release of LightGif / 轻动 GIF.

- Native portable Windows text-carousel GIF editor with live preview.
- Independent hold/transition timing, transparent backgrounds, font fitting and saved presets.
- Strict optional 500,000-byte export cap with palette/frame-rate fallback.
- Portable source layout, auto-discovered MSVC toolchain and independent decoder tests.
- Chinese and English README, source license, example GIF and Windows CI.
