# 使用说明

轻动 GIF · 文字动图制作器 1.0

一、怎么打开
解压文件夹，双击“LightGif.exe”即可。
软件完全离线运行，无需安装、无需管理员权限，无需安装 Python、Node、.NET 或 VC++ 运行库。
程序为 Windows 32 位原生 EXE，已在 Windows 10 22H2 x64 验证；Windows 11 与原生 32 位系统尚未实机验证。
本软件使用 Windows 自带组件和电脑已安装的字体。

二、最快使用方法
1. 在左侧文字框填写需要轮播的文案。
2. 选择字体，输入字号或拖动字号滑块。
3. 分别设置“停留时长”和“动画变化时长”。
4. 看右侧实时预览，满意后点击“导出 GIF”，选择保存位置。

三、两个时间怎么区分
停留时长：一条文字完整显示、保持不动的时间。
动画变化时长：当前文字向上退出，下一条文字进入的时间。
数值越大，停留越久，或切换越慢；两项独立调整。

默认：停留 2 秒，变化 0.6 秒。
三条文案每轮时长为 (2 + 0.6) × 3 = 7.8 秒。
若朋友觉得切换太快，可先把“动画变化时长”改为 0.8 或 1.0 秒。
停留时长支持 0.5–10 秒，变化时长支持 0.1–3 秒。
GIF 的时间精度为 0.01 秒；导出会保持设定的总时长。
只有一条文案时保持静止，无需来回切换。

四、文字和字号
默认三条文案：门窗维修 / 防水补漏 / 翻新改造。
“＋ 添加”最多可增加到 12 条；“↑”将该条向前移动；“×”删除该条。
空白条目在导出时跳过。
字号支持 12–200 像素，默认所有文案使用同一字号。
打开“文字太长时自动适配”后，软件会按最长的一条统一缩小字号，以保持轮播时字体大小一致。
预览区会显示实际采用的字号。
关闭自动适配后，文字放不下时会提示调整，并阻止输出被截断的文字。
字体列表来自当前电脑；无法使用所选字体时，软件会提示并尝试系统替代字体。

五、导出与体积
默认尺寸为 480 × 206 像素，胶囊按钮以外为透明背景。
可以调整图片尺寸、按钮渐变色、文字颜色、边框颜色和边框宽度。
“控制在 500 KB 以内”默认打开，以小于 500,000 字节为标准。
软件会优先压缩重复画面，必要时减少颜色或动画帧数；保持尺寸、文案和设定的时长。
如果当前尺寸和文案条数仍无法满足限制，会提示调整，不会悄悄保存超限文件。
确实需要更大的文件时，可取消这个体积限制。
导出成功后会显示实际大小及保存位置。

六、保存常用方案
“保存方案”会将文案、字体、字号、两个时长、颜色、尺寸及体积限制保存到 .gifcfg 文件。
下次用“打开方案”恢复后即可继续修改。
随包的“default.gifcfg”与软件初始设置一致。
随包的“example.gif”展示停留 2 秒、变化 0.6 秒的默认效果。

七、便携说明
日常使用只需要“LightGif.exe”这个文件，其他文件是说明和示例。
软件不上传文案或图片，不需要账号，也不调用外部生图服务。
关闭软件前，如需保留修改，请手动保存方案。

八、更新与回退
关闭程序后，将新版解压到独立目录。保留旧 EXE 与方案文件即可回退；删除程序目录即可卸载，无后台服务或自动更新。
